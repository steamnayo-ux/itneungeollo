\## 📱 프로젝트 소개



\*\*있는걸로\*\*는 집에 있는 식재료를 활용하여

지금 바로 만들 수 있는 메뉴를 추천해주는 Android 앱입니다.



배달 음식의 비용이 부담되거나, 냉장고에 재료는 있지만

무엇을 만들어야 할지 고민되는 상황에서 아이디어를 얻어 제작했습니다.



사용자가 가지고 있는 재료를 선택하거나 직접 입력하면

레시피의 필수 재료와 비교하여 \*\*현재 만들 수 있는 레시피를 추천\*\*합니다.



새로운 재료를 구매하도록 유도하기보다

\*\*현재 가지고 있는 식재료를 최대한 활용하는 것\*\*을 핵심 방향으로 설계했습니다.



> \*\*"없는 재료를 찾지 말고, 있는 걸로 먹자."\*\*



\---



\## 🎯 프로젝트 목표



\### 문제



\* 집에 재료가 있어도 무엇을 만들어야 할지 모르는 경우가 많음

\* 레시피를 검색하면 없는 재료를 추가로 구매해야 하는 경우가 많음

\* 간단한 한 끼를 위해 여러 레시피를 직접 비교해야 하는 불편함



\### 해결 방법



사용자가 가지고 있는 재료를 입력하면

앱이 레시피와 비교하여 만들 수 있는 메뉴를 선별합니다.



```text

재료 입력

&#x20;  ↓

재료 이름 정리

&#x20;  ↓

레시피 필수 재료 비교

&#x20;  ↓

만들 수 있는 레시피 필터링

&#x20;  ↓

보유 재료 활용도 계산

&#x20;  ↓

조리 시간 기준 정렬

&#x20;  ↓

추천 결과 제공

```

\# ✨ 주요 기능



\## 1. 🥕 재료 선택



미리 제공되는 재료 목록에서 현재 가지고 있는 식재료를 선택할 수 있습니다.



\### 기본 재료



\* 🥚 계란

\* 🍚 밥

\* 🥬 김치

\* 🧅 양파

\* 🌱 대파

\* 🧈 두부

\* 🍖 햄

\* 🐟 참치

\* 🥔 감자



선택한 재료는 \*\*내가 가진 재료\*\* 영역에 표시되며 개별적으로 삭제할 수 있습니다.



재료 목록은 스크롤이 가능하도록 구현하여 재료가 많아져도 추천 버튼을 사용할 수 있도록 구성했습니다.



\---



\## 2. ✏️ 재료 직접 입력



기본 목록에 없는 재료는 사용자가 직접 입력할 수 있습니다.



예:



```text

계란, 밥, 김치

```



쉼표를 기준으로 여러 재료를 한 번에 입력할 수 있으며,

입력한 재료는 기존에 선택한 재료와 함께 관리됩니다.



\---



\## 3. 🔤 재료 이름 정규화



같은 재료를 다양한 형태로 입력하더라도

앱 내부에서 동일한 재료로 처리할 수 있도록 문자열 기반 정규화 기능을 구현했습니다.



예:



```text

달걀

계란

계란 2개

달걀 두 개

```



↓



```text

계란

```



현재는 기본적인 문자열 비교 방식으로 구현했으며,

향후 자연어 처리 및 AI 기반 재료 인식 기능으로 확장할 수 있습니다.



\---



\## 4. 🧂 기본 양념 자동 처리



일반적인 가정에서 기본적으로 구비하고 있다고 가정하는 양념은

사용자가 별도로 선택하지 않아도 자동으로 보유한 것으로 처리합니다.



\### 기본 양념



\* 소금

\* 설탕

\* 진간장

\* 식용유

\* 참기름

\* 고춧가루

\* 고추장

\* 된장

\* 다진 마늘

\* 후추

\* 식초



기본 양념은 검색 조건에서는 제외하여

사용자가 별도로 선택하지 않아도 레시피를 만들 수 있도록 처리했습니다.



단, 레시피 상세 화면에서는 해당 레시피에서 실제 사용하는 기본 양념을 표시합니다.



\---



\## 5. 🍳 레시피 매칭 및 추천



사용자가 선택한 재료와 레시피의 재료를 비교하여

현재 만들 수 있는 레시피를 선별합니다.



\### 추천 기준



1\. 필수 재료가 모두 충족되는 레시피

2\. 사용자가 가지고 있는 재료를 많이 활용하는 레시피

3\. 선택 재료 활용도가 높은 레시피

4\. 조리 시간이 짧은 레시피



예를 들어 다음 재료를 가지고 있다면:



```text

계란 + 밥 + 김치

```



다음과 같은 메뉴를 추천할 수 있습니다.



```text

김치볶음밥

김치 계란덮밥

계란밥

계란국

```



필수 재료가 부족한 레시피는 기본 추천 목록에서 제외합니다.



\---



\## 6. ⭐ 추천 결과 카드



추천 결과는 카드 형태로 표시합니다.



각 카드에는 다음 정보를 제공합니다.



\* 🍳 레시피 이름

\* ✅ 필수 재료 충족 정도

\* ⭐ 내 재료 활용 수

\* ⏱️ 조리 시간

\* 📖 레시피 상세 보기



예:



```text

┌──────────────────────────┐

│ 1. 김치볶음밥             │

│                          │

│ 필수 재료  2 / 2 ✅       │

│ 내 재료 활용  3개 ⭐      │

│ ⏱ 15분                   │

│                          │

│       \[ 레시피 보기 ]    │

└──────────────────────────┘

```



\---



\## 7. 🍽️ 다른 메뉴 보기



추천 결과가 여러 개일 경우



\*\*`다른 메뉴 보여줘 🍽️`\*\*



버튼을 통해 추가 레시피를 확인할 수 있습니다.



현재는 한 번에 3개의 레시피를 보여주고,

추가 레시피가 있을 경우 다음 추천 목록을 표시하도록 구현했습니다.



\---



\## 8. 📖 레시피 상세



추천된 레시피의 \*\*레시피 보기\*\* 버튼을 누르면 상세 화면으로 이동합니다.



상세 화면에서는 다음 정보를 제공합니다.



\### 필수 재료



해당 레시피를 만들기 위해 반드시 필요한 재료



\### 있으면 좋은 재료



없어도 기본적인 조리가 가능하지만 있으면 좋은 재료



\### 기본 양념



해당 레시피에서 실제 사용하는 기본 양념



\### 만드는 방법



조리 과정을 순서대로 표시



예:



```text

🍳 김치볶음밥



⏱ 조리 시간: 15분



필수 재료

✓ 밥

✓ 김치



있으면 좋은 재료

○ 계란

○ 대파

○ 김가루



기본 양념 🧂

✓ 식용유

✓ 참기름

✓ 후추



만드는 방법

1\. 김치와 대파를 잘게 썬다.

2\. 식용유를 두르고 볶는다.

3\. 밥을 넣고 함께 볶는다.

4\. 후추로 간을 한다.

5\. 참기름을 넣어 마무리한다.

```

\# 🧩 데이터 구조



레시피는 `Recipe` 데이터 클래스를 기준으로 관리합니다.



```text

Recipe

├── id

├── name

├── time

├── ingredients

├── optionalIngredients

├── seasonings

└── steps

```



| 필드                    | 설명                  |

| --------------------- | ------------------- |

| `id`                  | 레시피 고유 번호           |

| `name`                | 레시피 이름              |

| `time`                | 예상 조리 시간            |

| `ingredients`         | 반드시 필요한 일반 재료       |

| `optionalIngredients` | 있으면 좋은 재료           |

| `seasonings`          | 해당 레시피에서 사용하는 기본 양념 |

| `steps`               | 조리 방법               |

\# 🚀 향후 개발 계획



현재 프로젝트는 \*\*MVP 형태의 Android 앱 프로토타입\*\*으로 구현했습니다.



\### 1. 레시피 데이터 확장



현재 약 30개의 레시피를 기반으로 동작하며

향후 다양한 재료와 레시피를 추가할 예정입니다.



\### 2. JSON 기반 데이터 관리



현재 코드 내부에서 관리하는 레시피 데이터를 JSON 파일로 분리하여

데이터와 UI/로직을 분리할 예정입니다.



\### 3. Room Database



레시피 데이터가 많아질 경우 Room Database를 적용하여

로컬 데이터 관리 구조로 확장할 예정입니다.



\### 4. 자연어 기반 재료 입력



현재의 단순한 입력 방식에서 발전하여 다음과 같은 자연어 입력을 분석할 수 있도록 확장할 예정입니다.



```text

계란 2개랑 양파 반 개밖에 없어.

```



사용자의 입력에서 재료와 수량을 자동으로 추출하여

레시피 추천에 활용하는 것을 목표로 합니다.
